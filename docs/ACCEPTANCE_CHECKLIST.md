# 验收清单

任何一项失败都应阻止发布，并在验证报告中给出具体字段和证据。

## 1. 输入与可复现性

- [ ] 普通战斗日志、RAW战斗日志、CustomData、日期配置和规则配置均有 SHA-256。
- [ ] 三种日志输入按日期和时间正确对齐。
- [ ] 相同输入与代码重复运行生成相同的分析结果。
- [ ] 时间、团队名单、Boss尝试和阶段边界均已识别或明确覆盖。
- [ ] 日期专用数据未写死在通用规则代码中。
- [ ] 原始日志不被分析程序修改。

## 2. 2026-11-18 黄金基准

- [ ] 分析 JSON 与冻结的黄金快照逐字段比较。
- [ ] 团队成员、职业和职责一致。
- [ ] Boss顺序、尝试次数和战斗边界一致。
- [ ] DPS总伤害、战斗时长和排序一致。
- [ ] 每项机制的玩家、次数、权重和数值一致。
- [ ] 灭团原因、时间线和责任归属一致。
- [ ] 个人错误排行和灭团错误排行一致。
- [ ] 展示文案与当前网站的有效中文内容一致。
- [ ] 所有预期差异都有规则变更记录和人工批准。

## 3. 数据完整性

- [ ] 每名玩家的错误总数等于全部明细权重之和。
- [ ] 团队总错误数等于个人错误数之和。
- [ ] 同一行为没有被多个规则重复计错。
- [ ] “只出数字”的规则没有生成冗长个人名单。
- [ ] 0错误成员仍在排行末尾，并显示“没犯错误”。
- [ ] 只有确认属于第二人称代词的事件才映射到日志记录者。
- [ ] 名为“你”“你的”或“你的XXX”的真实玩家保持原名，没有被错误归给日志记录者。
- [ ] 没有英文占位文案或未翻译表头。
- [ ] 未发生的机制显示“本次未发生”，不生成虚构错误。

## 4. 证据可复算

- [ ] 每条发现都有唯一 `finding_id` 和 `rule_id`。
- [ ] 每条发现都有原始日志行号、时间窗和证据用途。
- [ ] 伤害总和可以从证据行重新求和。
- [ ] 覆盖率可以从光环区间和有效战斗区间重新计算。
- [ ] 施法和打断结论包含施法开始、打断或完成事件。
- [ ] 驱散惩罚包含驱散事件及对应伤害。
- [ ] 连锁爆炸包含完整批次、时间间隔和根因依据。
- [ ] 所有低置信度项进入AI复核包。

## 5. 职责和豁免

- [ ] 事件解析前已从 CustomData、GUID、团队快照和配置冻结玩家名单。
- [ ] 姓名解析优先使用GUID，无GUID时使用完整姓名最长匹配。
- [ ] 没有对原始日志执行“你/你的”全局字符串替换。
- [ ] “第二人称所有格+技能”和“完整玩家名”冲突时已按事件语法消歧。
- [ ] 无法消歧的姓名带有候选列表和 `ambiguous_name`，并进入AI复核。
- [ ] 坦克、治疗、物理近战、法术远程按实际技能逐人判断。
- [ ] 猎人全程近战技能时按近战。
- [ ] 近战萨满和惩戒骑按近战。
- [ ] 治疗不因未打普通小怪计错。
- [ ] 坦克不参加普通输出职责检查。
- [ ] 纳尔穆恩红蓝月主坦克豁免。
- [ ] 因塔苟斯亲和与开怪冰抗排除坦克。
- [ ] 阿诺玛鲁斯开怪奥术防护排除坦克。
- [ ] 桑夫接Boss的坦克不检查虚无行者。
- [ ] 破碎者二阶段术士与牧师不检查活体碎块。
- [ ] 孟菲斯托斯55%停手排除坦克。
- [ ] 孟菲斯托斯引眼人与陪同驱散人不检查爬行者。

## 6. 最新规则回归

- [ ] Buff和药剂只累计战斗断档，超过60秒才计错。
- [ ] 风怒覆盖率低于80%时按受影响近战人数加权。
- [ ] 暗影诅咒覆盖率不计错。
- [ ] 语言诅咒只检查麦迪文。
- [ ] 国王诅咒阈值为80%，其他需判错诅咒为90%。
- [ ] 纳尔穆恩猫头鹰排除全死前最后10秒。
- [ ] 因塔苟斯火冰亲和不统计萨满，自然亲和统计萨满。
- [ ] 阿诺玛鲁斯爆炸人均实际伤害严格大于1200才计错。
- [ ] 阿诺玛鲁斯前三个超载点名使用剩余8秒规则。
- [ ] 2026-11-18 Tbug超载连锁爆炸总伤害为184139且只计1次根因。
- [ ] 国王小怪存活超过10秒才检查未攻击者。
- [ ] 桑夫裂隙诅咒只在裂隙回馈致死时追责。
- [ ] 桑夫仇恨溢出只有直接致死才计错。
- [ ] 库鲁尔普通约1300暗影新星不当作印记驱散惩罚。
- [ ] 库鲁尔同一换坦窗口达到7层只算一批。
- [ ] 孟菲斯托斯爬行者实际吸到法力后才计错。
- [ ] 孟菲斯托斯30%以下不检查爬行者。
- [ ] 挣脱镣铐按被炸人数计次。

## 7. 自动化质量

- [ ] JSON符合版本化 Schema。
- [ ] Python文件可通过语法编译。
- [ ] 解析器和规则单元测试通过。
- [ ] 姓名测试覆盖“你”“你的”“你的技能名”、姓名前缀冲突和无GUID歧义。
- [ ] 黄金快照测试通过。
- [ ] 新旧实现差异报告为空或已批准。
- [ ] AI复核结果哈希对应当前证据包。
- [ ] AI复核无待修正、被拒绝或缺证据项目。
- [ ] 验证失败时未写入网站目录。

## 8. 网站与展示

- [ ] 模板与日期数据分离。
- [ ] 首页日期列表包含新日期且链接正确。
- [ ] `reports/YYYY-MM-DD/` 可直接打开。
- [ ] 相对路径适用于 GitHub Pages 子路径部署。
- [ ] 桌面宽度下所有区域、表头和跳转正常。
- [ ] 手机宽度下没有被截断、重叠或异常横向溢出。
- [ ] 表格在手机端按既定响应式样式展示。
- [ ] 页面文字清晰，没有为合图而缩放造成模糊。
- [ ] 数据中的所有中文文案正确显示。
- [ ] 浏览器控制台无脚本错误和资源404。

- [ ] 查看所有4人以上死亡或高额团伤事件。
- [ ] 查看所有低置信度结论。
- [ ] 查看职责识别及人工覆盖。
- [ ] 查看与上周和黄金结果的显著变化。
- [ ] 确认最终页面与分析JSON来自同一次运行。
- [ ] 发布操作由用户明确授权。
